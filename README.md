# micro-hub

**Rascunho.** Não há código, release nem versão utilizável. Nada aqui deve ser lido como
compromisso de escopo, prazo ou API.

A direção em estudo é o **MicroHub**: um hub local no PC (Windows) para trabalhar com placas
ESP32 e Raspberry Pi Pico, com firmware em MicroPython. A ideia é reunir num só lugar o que
hoje fica espalhado entre editor, terminal, gravador de firmware e console serial:

- cadastro e organização de placas e projetos (CRUD);
- painel com o estado do que está conectado e em execução;
- envio de programas, execução e recuperação de placas;
- simulação como apoio, sem substituir o hardware.

Nada disso existe ainda. A interface também não foi desenhada: depende de pesquisa de
referências visuais e da criação dos assets de logo.
